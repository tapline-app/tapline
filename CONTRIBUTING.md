# Contributing to Tapline

Thanks for contributing! 🎉

## 🚀 Quick Start

1. Fork the repository
2. Clone: `git clone https://github.com/your-username/tapline.git`
3. Create branch: `git checkout -b feature/your-feature`
4. Make changes
5. Commit: `git commit -m "feat(scope): description"`
6. Push: `git push origin feature/your-feature`
7. Create Pull Request

## 📝 Commit Message Format

Use this format:

```
<type>(<scope>): <description>
```

### Types
- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation
- `style`: Code formatting
- `refactor`: Code refactoring
- `test`: Adding tests
- `chore`: Maintenance

### Scopes
- `gateway`, `mail`, `chat`, `meet`, `calendar`, `ai`
- `auth`, `notification`, `storage`
- `frontend`, `shared`, `infra`, `docs`

### Examples
```bash
feat(mail): add email compose functionality
fix(chat): resolve message duplication issue
docs(readme): update setup instructions
```

## 🧪 Testing

- Write tests for new features
- Maintain 70% code coverage
- Run tests before PR: `pnpm test`

## 🔍 Code Review

- PRs need atleast 1 approvals
- Keep PRs small (<400 lines)
- Respond to reviews within 24 hours
